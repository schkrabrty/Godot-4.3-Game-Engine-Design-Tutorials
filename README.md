# Soumya-Class-Demo

In this tutorial, I will show you how can you build games for XR using Godot Game Engine.

Please consider [this tutorial series](https://www.youtube.com/watch?v=fxZoXfX4oBo&list=PLfX6C2dxVyLxXl3gJwakzdqRaV7WKlqFR), and [this tutorial](https://www.youtube.com/watch?v=BrNZs4XzU0w&t=761s) to understand the project better.

Please consider the `main_xr`, `xr_Player`, and the `pickable_box` scenes from the `Scenes` folder which shows the XR implementation in Godot. This project is made to run on Meta Quest 2, 3 and Pro devices. In order to get the project work properly on the devices, you need to follow bunch of steps, which are not properly mentioned on Online sources. So, I will describe them below.

First of all, you need to download and install `Android Studio`, `Blender`, and `OpenJDK` (Version 17 to be specific). You need to download the specific version of OpenJDK because Godot cannot detect other versions of OpenJDK at all. Once you install all these softwares, open `Android Studio`, and click on `More Actions` and then `SDK Manager`. In the opened window, you need to select the latest version of Android SDK and at least 1 or 2 previous versions so that Godot will be happy about it. Next, click on `SDK Tools` tab, and select these options - `Android SDK Build-Tools 36`, `NDK (Side by Side)`, `Android SDK Command-line Tools`, and `CMake`. After selecting all these options, click on `OK` which will install all these selected packages.

Godot now wants to get the path of the `OpenJDK`, and `Android SDK`. Go to Godot and click on `Editor` on the Menu bar. Then click on `Command Palette` -> `Editor Settings`. This will open a new window. Search for `Export` and then choose the `Android` option. Then you need to provide the path of your JDK and Android SDK installations. I am using a MAC, and so, the path of my JDK is - `/usr/local/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home` and the path of my Android SDK is `/Users/soumyajitchakraborty/Library/Android/sdk`. Please make sure that you are using `OpenJDK` version 17. Now, we are still not done yet. You need to go to the `Android SDK` folder directory manually and find the `ndk` folder. The folder will most likely consists of the latest version of `Android NDK`. However, Godot can only read one specific version of `Android NDK`. So, I found an easy workaround to solve this problem. Open the `ndk` folder and you will be able to see a folder with the latest `Android NDK` version number. Simply select the folder and rename it to - `23.2.8568313`. I found this hack works. Once you do that, Godot will be happy.

Now, we need to setup some other stuffs in Godot. First, click on `Editor` on the menu bar and then click on `Manage Export Templates`. In the opened window, just click on `Download and Install`. This will install necessary build templates for your Godot Game Engine. Once this is finished, click on `Project` on the menu bar of Godot and then click on `Install Android Build Template`. This will install Android build templates in your computer which is required if you want to build XR games for devices like `Meta Quest 3`. After this process, click on `AssetLib` next to the `Script` option in the top middle area of the Godot editor. In the search bar then type `XR` and search for existing plugins. Now, we need to download and install some plugins and they are - `Godot OpenXR Vendors Plugin v3`, `Godot XR Tools for Godot 4`, and `Godot XR Android OpenXR Loaders`. If you click on these plugins, they will ask you to `Download` them. However, they will not be installed automatically. After they are downloaded, you need to click them once again to manually install them on your computer. Now, we have installed all the required packages, and hopefully made Godot to run XR projects.

Before you go to the next step, click on `Project` in the menu bar and then click on `Project Settings`. In the opened window, scroll down to the `XR` section on the left side of the window. Click on `OpenXR` and then click on `Enabled`. Next, in the same area, do these steps - (1) Change the `Reference Space` to `Local Floor`, (2) turn on `Hand Interaction Profile` for hand tracking (optional), (3) turn on `Eye Gaze Interaction` for eye tracking (optional), and (4) `Hand Tracking Aim` again for hand tracking (optional). Next, click on `Shaders` on the left side of the window below the `OpenXR` settings, and click on the checkbox next to `Enabled` to turn the Open XR shaders on. Finally, go to the `Plugins` tab located on the top of the same window, and click on the checkbox to enable `Godot XR Tools`. If you do not set these things up, XR will not work. 

Lastly, when you want to export a build for a device like `Meta Quest 3`, you need to click on `Project` on the menu bar, and then click on `Export`. From the opened window, click on `Add` and then add the `Android` build. Next, click on `Android (Runnable)` and now we need to setup the build to build and run properly on the headset. So, first, turn on `Use Gradle Build`. Next, scroll down to the `Package` section and give a name to your app. Next, scroll down to the `XR Features` section and change the `XR Mode` to `OpenXR` if it is not already selected to that option by default. Then in the same section, turn on `Enable Meta Plugin`. Then scroll way down to `Meta XR Features` and choose the options whatever you need to turn on in your headset. However, don't forget to turn on the support options for your headset. For example, if you are going to build on a `Meta Quest 3` headset, then you need to turn on `Quest 3 Support` option from this section. Then you can click on `Export Project` button. Save the project as an `apk` file. Next, download and install `Meta Quest Developer Hub` on your computer. Plug your headset in to your computer. It will show you a prompt inside your headset. Click on `Always Allow this Computer` button. Next, open the `Meta Quest Developer Hub` app on your computer and it should detect your headset. Follow the on screen instructions to turn on `Developer Mode` in your headset. Finally, you will be able to see your device portal in the software. Once you see that, simply drag and drop your `apk` file on the `Meta Quest Developer Hub` app. It will show you if you want to install the app in your headset or not. Just drop the `apk` file on the headset drag and drop area and it will start to install the app on your device. Once the app is installed, you can click on the `Launch App` option next to the installed app in the `Meta Quest Developer Hub` app. If everything is setup properly, you will be able to see your first XR game built in Godot.
